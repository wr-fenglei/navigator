# 实施

主 agent 维护总体计划, 选择依赖和资源已满足的循环, 执行后核验产物与证据, 记录结果并安排下一步

## 调度与调整

修改范围不冲突才并行, 可用且获准时使用 subagent, 说明目标, 输入, 范围和验收取证要求, 主 agent 同时处理其他工作, 没有相应工具就按依赖自己完成

循环按待启动, 执行中, 待验证, 已通过或受阻记录, 检查实际产物后才启动依赖它的循环, 执行者自报完成不能代替核验

局部失败就修复验证, 路径或依赖失效就回到拆解, 目标或验收要变就回到探索请用户决定, 缺条件就记录阻塞并继续独立工作, 重试要有新条件或取证目标, 无依据时不重复尝试

验证通过后继续交付, 内容变化, 失败或仍有疑点时才补查, 恢复或重试先核对记录, 产物版本, 环境和实际操作结果, 修正过时状态, 避免重复写入或派发仍在执行的工作

## 暂停, 后续运行与完成

用户暂停或停止时停止派发, 通知本任务的 subagent, 核对进行中的操作并保存进度

用户明确要求之后继续, 定时运行或监控时, 用宿主工具建立或复用调度, 写清记录位置, 验收, 授权, 预算和停止条件, 保存调度标识, 只有工具确认成功才承诺后续运行, 不可用就说明缺少什么条件

每次恢复先核对状态, 无变化时保持安静, 有可处理的变化, 完成, 失败或需要决定时再通知, 用户另有通知要求则沿用, 完成或停止时关闭本任务创建的后续调度并核对结果

沿实际使用流程核对本次验收, 证据须对应当前产物, 主观体验保留给用户确认, 汇报先说交付与是否完成, 再给证据和必要限制, 未通过的验收列出剩余项与下一步
